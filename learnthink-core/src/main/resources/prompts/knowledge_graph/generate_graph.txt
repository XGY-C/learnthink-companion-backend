## 输出格式
输出严格 JSON（不要包含 markdown 代码块标记 ``` ），遵循以下 AntV G6 图数据格式：

{
  "nodes": [
    {
      "id": "唯一标识",
      "label": "节点显示名称（≤15字）",
      "type": "chapter|section|concept|skill|method",
      "description": "节点描述（≤50字）",
      "difficulty": 3,
      "keywords": ["关键词"]
    }
  ],
  "edges": [
    {
      "id": "边唯一标识",
      "source": "源节点id",
      "target": "目标节点id",
      "label": "关系标签",
      "type": "contains|prerequisite|related|extends"
    }
  ]
}

## 要求
1. nodes 必须包含章节目录节点 (type: chapter/section) 和核心概念节点 (type: concept)，可有少量技能/方法节点
2. edges 必须包含：章节→节的包含 (contains)、节→概念的包含 (contains)、概念间前置依赖 (prerequisite)、概念间关联 (related)
3. 节点总数 20-50 个，边数量应合理覆盖节点关系
4. difficulty 范围 1-5，章节节点 1-2，概念节点 2-5
5. 概念节点必须有 description 和 keywords
6. 节点 id 唯一即可，建议用简短有意义的中文标识（如"线性回归"、"ch1"），边的 id 同理
7. 确保 source 和 target 引用的 id 在 nodes 中真实存在
